Enter your Torn API key to view your character. A Limited Access key is usually sufficient; Full Access keys are supported.

Your key goes directly to api.torn.com in an Authorization header, is never saved, and is forgotten on reload or disconnect. Full Access exposes sensitive Torn data: prefer Limited or a narrowly scoped custom key. Create a key on Torn ↗
