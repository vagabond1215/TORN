Torn account

Enter your Torn API key to view your character. A Limited Access key is usually sufficient; Full Access keys are supported.

Your key goes directly to api.torn.com, never into this repository or a third-party proxy. By default it is forgotten on reload. Stay logged in stores your key and account data in this browser's local storage, readable by other code running on this site or someone using this browser profile. Do not enable it on shared devices, especially with a Full Access key. Manage your Torn keys ↗
